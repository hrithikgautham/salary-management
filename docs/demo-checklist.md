# Five-minute demo script

1. Show the sign-in screen and explain that Supabase Auth owns credentials.
2. Sign in with a test HR account created in Supabase Auth.
3. Point out headline employee metrics and compensation summaries grouped by currency.
4. Search for an employee number or name. Change country/department filters and page size to demonstrate server-side pagination.
5. Open an employee, edit salary and enter a reason, then save.
6. Show the changed current compensation and audit entry with old/new values and actor.
7. Attempt a negative salary or stale update to show validation/conflict handling.
8. Briefly show requirements, architecture, and decisions docs and explain the deliberate non-goals.

Use only synthetic data and a demo account. Do not show environment variables, keys, tokens, or real salary information in the recording.
